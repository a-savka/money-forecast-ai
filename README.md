# MoneyForecast AI

ИИ-прогнозирование расходов, которое заранее предупреждает о кассовых разрывах.
Учебный проект по дисциплине «Стартап-экосистемы».

Команда: Савка Андрей, Баранов Кирилл, Хрисфанова Виктория, Максименко Алексей.

## Что умеет MVP

| Функция | Статус |
|---|---|
| Операции: ручной ввод, импорт CSV/Excel-выписки (пресет Т-Банка + автоопределение колонок), дедупликация | Реально |
| Подключение банка (Т-Банк, Сбер, Альфа, ВТБ, Ozon) | Мок: согласие + синтетические операции |
| Чек по QR-коду (камера или строка из QR) | Реально |
| Скриншот операции из банковского приложения → черновик | Vision-LLM (GigaChat), без ключей — мок |
| Автокатегоризация: правила пользователя → ключевые слова → категория банка → MCC; обучение на правках | Реально |
| Аналитика: структура трат, сравнение с прошлым месяцем, динамика за 6 месяцев | Реально |
| Прогноз трат и баланса на неделю/месяц, коридор P10–P90, риск кассового разрыва, «можно тратить в день» | Реально |
| 4 стратегии прогноза (H0–H3) и бэктест для их сравнения | Реально |
| Советы: правила + переформулировка LLM (суммы не меняются) | Реально / LLM — мок без ключей |
| Онбординг с первым прогнозом ≤ 2 минут, замер time-to-value | Реально |
| Подписка Free/Premium, пробный период 7 дней, paywall | Мок (без платежей) |
| Семейный бюджет, лимиты по категориям, уведомления | Мок (UI + простая логика) |
| Android-приложение (Capacitor) | Debug APK |

### Гипотезы прогноза

| ID | Стратегия | Идея |
|---|---|---|
| H0 | `baseline` | Средний дневной расход за 30 дней × оставшиеся дни |
| H1 | `statistical` | Регулярные платежи по расписанию + траты по дням недели, эффект зарплаты, сезонность (по умолчанию) |
| H2 | `stat_llm` | H1 + поправки LLM на праздники и тренды; в LLM уходят только агрегаты |
| H3 | `ml_gbm` | Глобальная LightGBM на синтетических профилях, квантильная регрессия |

Результаты бэктеста на синтетике — `docs/backtest/report.md`; как прогнать на реальных
выписках команды — `docs/backtest/REAL_DATA.md`.

## Структура

| Папка | Что внутри |
|---|---|
| `backend/` | FastAPI: операции, импорт, категоризация, прогнозный движок, бэктест, LLM-слой, моки |
| `frontend/` | React-приложение (web) + Capacitor-проект для Android |
| `docs/` | План MVP, сценарий демо, отчёты бэктеста, образцы файлов для демо |

## Быстрый старт

```bash
cp .env.example .env
docker compose up --build
docker compose exec api python -m scripts.train_ml_gbm   # модель H3, ~30 с (необязательно)
```

- Web-приложение: http://localhost:5173
- API и Swagger: http://localhost:8000/docs

Вход — под одним из демо-профилей (данные за 12 месяцев загружаются автоматически)
или «с чистого листа» через онбординг. Сценарий показа — `docs/DEMO.md`.

### Реальная LLM

По умолчанию `LLM_PROVIDER=mock` — всё работает без ключей и сети. Для GigaChat или YandexGPT
заполните ключи в `.env` (см. `.env.example`), поставьте `LLM_PROVIDER=gigachat|yandexgpt`
и проверьте подключение: `cd backend && uv run python -m scripts.llm_smoke`.

## Разработка без Docker

```bash
# backend
cd backend
uv sync
DATABASE_URL=sqlite:///./dev.db uv run alembic upgrade head
DATABASE_URL=sqlite:///./dev.db uv run uvicorn app.main:app --reload

# frontend
cd frontend
npm install
npm run dev
```

Проверки:

```bash
cd backend && uv run ruff check . && uv run pytest
cd frontend && npm run lint && npm run typecheck && npm test
cd backend && uv run python -m scripts.run_backtest      # отчёт H0–H3 → docs/backtest/
```

## Мобильное приложение (Android)

Нужны JDK 21 и Android SDK (путь в `frontend/android/local.properties`: `sdk.dir=...`).

```bash
cd frontend
npm run android:build
# APK: frontend/android/app/build/outputs/apk/debug/app-debug.apk
```

Телефон и компьютер должны быть в одной сети. Адрес API (`http://<IP-компьютера>:8000`)
задаётся на экране входа → «Настройки сервера»; пересобирать APK не нужно.
Уведомления на Android приходят как системные (при первом показе приложение спросит разрешение).

Подробный план и статус задач — `docs/MVP_PLAN.md`.
