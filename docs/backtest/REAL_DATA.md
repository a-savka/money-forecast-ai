# Бэктест на реальных выписках (W4-6)

Цель — честно сравнить гипотезы H0–H3 на данных, которых модели не видели.
Синтетика (`report.md` рядом) подходит для отладки, но ML (H3) обучен на похожем генераторе.

## 1. Выгрузить выписки

Каждый участник команды выгружает выписку **за 6+ месяцев** из приложения банка:

- Т-Банк: «Счёт → Выписка → CSV» (формат распознаётся автоматически);
- другие банки: CSV или Excel — колонки «дата», «сумма», «описание» найдутся по заголовкам.

Несколько карт одного человека — несколько файлов в одной папке.

## 2. Разложить по папкам (обезличенно)

```
data/private/            ← в .gitignore, в репозиторий не попадает
├─ person1/
│  ├─ tbank.csv
│  └─ sber.xlsx
├─ person2/
│  └─ alfa.csv
└─ ...
```

Имена папок попадают в отчёт, поэтому — `person1`, `person2`, без ФИО.
Перед тем как показывать отчёт, проверьте `cases.csv`: в нём только суммы и даты, без описаний операций.

## 3. Запустить

```bash
cd backend
uv run python -m scripts.run_backtest --statements ../data/private --out ../data/private/report
# с реальной LLM для H2 (нужны ключи в .env):
LLM_PROVIDER=gigachat uv run python -m scripts.run_backtest --statements ../data/private --out ../data/private/report
```

Выписки проходят тот же конвейер, что импорт в приложении (разбор → категоризация → дедупликация),
но сохраняются только во временную базу в памяти.

## 4. Что выносить на слайд

- таблицу из `report.md`: WAPE, MAE, покрытие P10–P90 по стратегиям;
- сравнение «синтетика vs реальные данные» — насколько просела каждая гипотеза;
- стоимость и время H2 (LLM) против выигрыша в точности;
- вывод: какую стратегию делаем основной (сейчас по умолчанию — H1 `statistical`).

Метрики кассового разрыва на выписках не интерпретируем: в выписке обычно нет начального остатка,
поэтому баланс в прогнозе считается от нуля.
