# Сценарий демо (3–4 минуты)

## Подготовка (за 10 минут до защиты)

1. `docker compose up -d` и открыть http://localhost:5173 (или APK на телефоне — см. README).
2. Сбросить демо-аккаунты к исходному состоянию, чтобы paywall и онбординг показывались заново:
   ```bash
   docker compose exec db psql -U mf moneyforecast -c "UPDATE users SET is_premium=false, trial_until=NULL;"
   ```
3. Распечатать / открыть на втором экране QR чека: `docs/samples/receipt_qr.png`.
4. Держать под рукой `docs/samples/tbank_dropout_3m.csv` и `docs/samples/bank_screenshot.png`.
5. Резервное видео — `docs/demo/demo-flow.webm` (если что-то не запустится).

## Запасные ходы

- **Нет сети / не отвечает API** — показать резервное видео.
- **Демо-профиль «сломан» экспериментами** — `POST /dev/seed` через Swagger (http://localhost:8000/docs)
  с `{"profile": "dropout"}` перезагрузит данные.
- **Нужен высокий риск разрыва** — профиль «Фрилансер (Алина)»: аренда 1-го числа, а гонорар ещё не пришёл.

## Ключевые цифры для слайда

- Time-to-value: онбординг до первого прогноза — секунды (цель < 2 мин), см. `GET /events/stats`.
- Бэктест на синтетике (72 прогноза на стратегию): H3 ML — WAPE 17,4%, H1 статистика — 22,8%,
  H2 статистика + LLM — 22,8%, H0 «как обычная аналитика» — 44,2% (`docs/backtest/report.md`).
- Время прогноза — ~30 мс; стоимость H2 — ≈ 0,2 ₽ за прогноз при ценах GigaChat Lite.
